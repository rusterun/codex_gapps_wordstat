# Google Sheets Wordstat Apps Script

Простой Google Apps Script для текущего листа Google Таблицы: генерирует начальные Wordstat-запросы по товарам, получает спрос через **Yandex Cloud Search API v2 / Wordstat** и пишет результаты обратно в таблицу.

## Колонки

Скрипт ищет колонки по заголовкам в первой строке, порядок колонок и название листа не важны:

- `Полное наименование товара`
- `Wordstat-запрос`
- `Спрос`
- `Дата обновления`
- `Комментарий`

Скрипт не изменяет колонку `Комментарий`.

## Настройка доступа

Нужны API-ключ Yandex Cloud / AI Studio и folder ID. Их нельзя хранить в ячейках. Откройте редактор Apps Script и один раз выполните:

```javascript
setWordstatCredentials('ВАШ_API_KEY', 'ВАШ_FOLDER_ID');
```

Значения будут сохранены в `PropertiesService` проекта Apps Script.

Старый OAuth-токен Wordstat/Direct больше не используется.

## Меню

После открытия таблицы появляется меню **Wordstat**:

- **Сгенерировать запросы** — заполняет пустые `Wordstat-запрос` на основе `Полное наименование товара` и не перезаписывает уже заполненные запросы.
- **Обновить спрос** — отправляет уникальные запросы в Wordstat API с учётом кэша.
- **Принудительно обновить** — игнорирует кэш и заново получает данные.
- **Проверить подключение** — проверяет наличие API-ключа/folder ID, доступность API и авторизацию.

## Wordstat API

Используется актуальный Yandex Cloud Search API v2 / Wordstat:

- базовый URL: `https://searchapi.api.cloud.yandex.net`
- проверка подключения: `POST /v2/wordstat/getRegionsTree`
- спрос по запросу: `POST /v2/wordstat/topRequests` с JSON `{ "folderId": "...", "phrase": "...", "numPhrases": 1 }`
- авторизация: HTTP-заголовок `Authorization: Api-Key <API key>`

`folderId` обязателен и добавляется в тело каждого запроса автоматически.

Кэш хранится в `PropertiesService` и действует 7 дней.

> Примечание для Google Apps Script: если `UrlFetchApp` выдаёт `Ошибка SSL` даже для официального домена `searchapi.api.cloud.yandex.net`, скрипт сначала делает запрос с обычной проверкой сертификата, а при такой SSL-ошибке повторяет запрос к тому же официальному URL с отключённой проверкой сертификата.
